# GAME: Rang Tubes 3D

- Status: in progress (batch 3)

- Target audience: Everyone incl. under-13 (declared child-directed, Families policy)
- Privacy policy URL: https://imajij.github.io/privacy.html

## Concept
Ball-sort ad genre in 3D glass tubes on a candy shelf: pour matching runs
between tubes until every tube is one color. Levels reverse-shuffle from a
solved state — provably solvable, endlessly generated.

## Core loop (30–120 s per vat, instant next)
Tap a tube (top ball lifts) → tap a target (whole matching run bounce-pours
over) → wrong color politely refuses → one-color tubes everywhere = SORTED!
confetti. 3→7 colors as vats climb.

## Controls (one thumb, portrait)
Taps only. UNDO button (3 free).

## Progression
Vat number saved; colors and shuffle depth scale.
